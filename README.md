# Kisaan Saathi

A React + Vite farming dashboard enhanced with a Node.js, Express.js, and MongoDB backend.

## Features
- JWT authentication
- User profile management
- Weather, mandi, news, schemes, and geocoding APIs
- Crop disease detection via image upload
- AI chat assistant integration
- Saved crops, favorite locations, and notifications

## Setup
1. Install dependencies: npm install
2. Copy .env.example to .env and add your API keys
3. Start MongoDB locally
4. Start the backend: npm run dev:server
5. Start the frontend: npm run dev

## API
- Frontend: http://localhost:5173
- Backend: http://localhost:5000
